**Ash** has Hall B saved and a messy meetup helper repo. Pasting files into [Claude chat](/learn/foundations/claude-basics) is slow. Ash wants something that **lives next to the files**.

**Claude Code** is Anthropic’s **agentic coding tool**: read a codebase, edit, run commands, work across the project. Chat is conversation; Claude Code is a **development agent** (terminal, IDE, desktop, or web).

Official source of truth: [Claude Code docs](https://code.claude.com/docs/en/overview) and [quickstart](https://code.claude.com/docs/en/quickstart). If steps drift, **trust the official site**.

## Claude chat vs Claude Code

| | Claude chat | Claude Code |
| --- | --- | --- |
| Best for | Writing, explaining, brainstorming | Editing a real repo, running commands |
| Where it runs | Browser / app chat | Terminal, IDE, desktop, or web coding UI |
| Sees Ash’s project | Only what Ash pastes | Files Ash allows in the project |

## Install (native path recommended)

Prefer the **native installer** (auto-updates). Alternatives: Homebrew, WinGet — see [setup docs](https://code.claude.com/docs/en/setup).

**macOS, Linux, WSL:**

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

**Windows PowerShell:**

```powershell
irm https://claude.ai/install.ps1 | iex
```

**Windows CMD:**

```batch
curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
```

New terminal, then:

```bash
claude --version
```

Also useful: `brew install --cask claude-code`, `winget install Anthropic.ClaudeCode`, or desktop/IDE links from the [overview](https://code.claude.com/docs/en/overview). Stuck? [Troubleshoot install](https://code.claude.com/docs/en/troubleshoot-install). On native Windows, Git for Windows helps Bash-style tools.

## Basic usage

```bash
cd /path/to/your/project
claude
```

First launch usually means browser login. You can **finish reading** without installing.

First asks Ash might try:

- “What’s the structure of this repo?”
- “Where is authentication handled?”
- “Explain this error: …” (paste a stack trace)

One-shot style (`claude -p "…"`) is in the docs — learn interactive first.

## Safety habits

- **Review diffs** before accept or commit.
- **Don’t paste secrets** (keys, passwords, customer data).
- Prefer a **small test repo** for session one.
- Same loop shape as [agentic workflows](/learn/foundations/agentic-workflows): plan → act → observe → verify.

See also: [Glossary — Claude Code](/glossary#claude-code).

## Takeaway

Claude Code = **coding agent in Ash’s project**. Official install → `claude` in a folder → ask about the repo → review every change.
