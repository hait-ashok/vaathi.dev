<p class="mono-label">Scene</p>

Someone tells **Ash**: “Just use Claude for the meetup.” Ash wonders — is that a cloud? A chat box? The thing that edits code?

**Claude** is Anthropic’s family of **language models** and the **products** around them. Think *assistant / model brand*, not cloud. Clouds like [AWS Bedrock](/learn/foundations/aws-bedrock-basics) may *host* Claude (and many other models).

## Anthropic product surfaces

| Surface | What Ash notices |
| --- | --- |
| **Chat** | Conversation UI for drafts, explainers, Q&A (e.g. claude.ai). |
| **API** | Ash’s app calls Claude programmatically. |
| **Claude Code** | A coding agent in the project folder — next: [Claude Code basics](/learn/foundations/claude-code-basics). |

You can learn Foundations with **any** chat assistant. No paid plan or API key required to finish reading.

## What “a Claude model” means

Anthropic ships versions over time. Treat “Claude” as a **line**: dialogue and text, with speed/cost/capability differences. Check the product’s docs for *which* version when it matters — we don’t pin numbers here so they don’t go stale.

## Tendencies (not scores)

People often use Claude for careful drafting, step-by-step explanations, and pasted documents. Still an LLM — it can invent facts. Keep [verify habits](/learn/foundations/personal-ai-workflow).

## Claude ≠ Bedrock

| | Claude | Bedrock |
| --- | --- | --- |
| Who makes it | Anthropic | Amazon Web Services |
| What it is | Models + Anthropic products | AWS door to many foundation models |
| Ash’s mental model | “The assistant / model” | “A cloud door to models” |

Same family via Anthropic **or** a cloud — different billing and permissions. See [how clouds serve frontier models](/learn/foundations/cloud-frontier-models).

## Neutral stance

vaathi.dev is not affiliated with Anthropic. We name Claude because beginners hear it often. Same [prompting](/learn/foundations/prompting-clear-communication) and [risk](/learn/foundations/limits-risks-responsible-use) habits apply across assistants.

See also: [Glossary — Claude](/glossary#claude).

## Takeaway

Claude = **Anthropic’s models and surfaces** (chat, API, Claude Code). Cloud hosting is a separate story.
