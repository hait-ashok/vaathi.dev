[Memory for agents](/learn/foundations/memory-for-agents) left Ash stuck: new chat, no Hall B. Here is the **smallest** code shape that fixes that — no special memory product.

<p class="mono-label">Scene</p>

Same meetup. We will (1) keep Hall B in **this** run’s message list, (2) **trim** when the list grows, (3) **save** the room so tomorrow’s run can inject it again.

## 1 — Short-term = the messages list

This run’s memory is already the `messages` list. Each turn appends; the model only sees what is still there.

```python
messages = [
    {"role": "system", "content": "Be concise. You help Ash book the meetup."},
    {"role": "user", "content": "What room is the meetup?"},
]
# after a tool result:
messages.append({"role": "tool", "content": "Hall B"})
```

While those lines stay in `messages`, Ash’s assistant still “knows” the room — for **this** session only.

## 2 — Cap it (budget)

Long chats fill the window. Cap the list — drop old turns, or crush them into one summary line.

```python
MAX = 12  # messages, not “forever”

def trim(messages, max_len=MAX):
    if len(messages) <= max_len:
        return messages
    head, tail = messages[:1], messages[-(max_len - 1) :]
    return head + [{"role": "system", "content": "[earlier turns summarized]"}] + tail
```

That is Ash’s **budget** knob in code.

## 3 — Long-term = a tiny fact store

Tomorrow’s empty chat needs a store **outside** the model. Dict today; file / DynamoDB later — same idea.

```python
FACTS = {}  # stand-in for a real store

def remember(key: str, value: str) -> None:
    FACTS[key] = value

def inject_facts(messages):
    if not FACTS:
        return messages
    blob = "; ".join(f"{k}={v}" for k, v in FACTS.items())
    return [{"role": "system", "content": f"Known facts: {blob}"}] + messages

remember("meetup_room", "Hall B")
messages = inject_facts(messages)
```

Next morning: load `FACTS`, call `inject_facts`, then start the [agent loop](/learn/build/agent-loop-in-code). Ash asks “which room?” — Hall B is already in the prompt.

## When to add vectors

If Ash had *dozens* of notes and needed “find the right one,” retrieve chunks first ([vectors in code](/learn/build/vectors-in-code)), then inject. For one room name, a fact store is enough.

## Takeaway

**List + trim + optional fact inject.** Same four knobs as Foundations; still one file; still Ash’s sticky note.
