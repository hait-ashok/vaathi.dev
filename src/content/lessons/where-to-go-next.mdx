<p class="mono-label">Scene</p>

**Ash** booked Hall B, learned that memory is sticky notes, that clouds are doors, and that Claude is a brand — not AWS. Foundations is done. The temptation is to open twelve new tools. Ash’s better move: **one habit**, then the next stage when ready.

You’ve covered the Foundations progression: intuition ([AI](/learn/foundations/what-ai-means), [Gen AI](/learn/foundations/what-gen-ai-is), [systems](/learn/foundations/systems-from-outside)) → core ideas ([LLMs](/learn/foundations/llms-plain-language), [embeddings](/learn/foundations/why-vectors-embeddings), [transformers](/learn/foundations/transformers-beginner), [how transformers work](/learn/foundations/how-transformers-work)) → build & compute ([pipeline](/learn/foundations/how-a-model-is-built), [GPUs vs CPUs](/learn/foundations/gpus-vs-cpus), [labeling](/learn/foundations/how-data-is-labeled), [evaluating outputs](/learn/foundations/bleu-and-rouge)) → practice ([prompting](/learn/foundations/prompting-clear-communication), [prompt patterns](/learn/foundations/prompt-engineering-in-practice), [risks](/learn/foundations/limits-risks-responsible-use)) → workflows ([personal](/learn/foundations/personal-ai-workflow), [tools](/learn/foundations/tool-landscape), [agents](/learn/foundations/agentic-workflows), [memory](/learn/foundations/memory-for-agents)) → products ([clouds](/learn/foundations/cloud-frontier-models), [Claude](/learn/foundations/claude-basics), [Claude Code](/learn/foundations/claude-code-basics), [Bedrock](/learn/foundations/aws-bedrock-basics)). Here’s how to continue without drowning.

## Keep it small

- Revisit one lesson when a tool confuses you.
- Practice the workflow on real tasks weekly — not every new app launch.
- Add tools only when a recurring job needs them.

## Stage 2 — Build

Next is [Build: Python to agents](/learn/build): just enough Python, then model calls, vectors, tool calls, and the agent loop in code. Same ideas as Foundations — now in the shape you will run.

## Stage 3 — Sandbox

After Build, open the [Sandbox](/sandbox): pick a scenario, change the prompt, watch the animated loop — brief, model, tool, result, answer — and match each card to the Python underneath.

## Community

Suggest topics on the [About](/about) page. This site stays free and open — no account required to learn.

## Takeaway

Curiosity scales better with **habits** than with hype. Ash is ready to practice.
