You don’t need every tool. You need a **map** so new logos don’t scramble your brain.

## Four rough regions

| Kind | What it’s for | Beginner cue |
| --- | --- | --- |
| **Chat apps** | Conversation, drafting, Q&A | Start here |
| **Image / media tools** | Generate or edit visuals/audio | Fun; check licenses |
| **APIs / builders** | Wire models into software | Later, if you build |
| **Agents** | Multi-step tool use | Powerful; start supervised |

## Choosing for a beginner task

Ask:

1. What’s the **deliverable**? (Email, outline, image, code snippet.)
2. How **wrong** can it be before it hurts?
3. Do I need **my private files** involved?
4. Is a simple chat enough, or am I overcomplicating?

Most early wins live in chat apps with careful prompting and verification.

## Takeaway

Map first, tour later. Prefer the simplest tool that can finish the job.
